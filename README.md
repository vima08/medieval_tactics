# Пепел и знамя

Локальная браузерная тактика о борьбе за перевал. Приказы детерминированы: прогноз атаки использует тот же расчёт, что и исполнение.

## Запуск

Требуется Node.js 20+.

```bash
npm install
npm run dev
```

Откройте адрес, напечатанный Vite (обычно http://localhost:5173/).

```bash
npm run build
npm test
```

На Windows PowerShell с запрещённым запуском сценариев используйте `npm.cmd` вместо `npm`.

## Режимы и цель

- **Обучение:** компактная карта, пошаговые подсказки, победа над вражеским командиром ♛.
- **Схватка с ИИ:** большая карта 18×18, три уровня сложности. Удерживайте хотя бы две из четырёх сигнальных точек в конце полного раунда. За раунд удержания серия получает одно очко; потеря контроля сбрасывает серию в ноль. Первой стороне, набравшей 5 очков и оторвавшейся от соперника, достанется победа. При равенстве борьба продолжается; на 12-м раунде сравниваются очки.
- **Локальный PvP:** два игрока по очереди собирают составы и играют на одном устройстве.

До большой схватки выберите 3–5 бойцов в пределах бюджета 25. На отряд доступно не более двух артефактов. Три готовых состава помогают начать быстро; собственный состав сохраняется в браузере.

## Управление

| Действие | Управление |
| --- | --- |
| Выбрать бойца / клетку / цель | ЛКМ |
| Ударить по хрупкому мосту | Shift + ЛКМ при выбранном бойце |
| Переключить своего бойца | Tab |
| Отменить выбор | ПКМ |
| Панорама | Перетаскивание ЛКМ по полю или стрелки |
| Масштаб | Колесо мыши |
| Обычная атака / особый приём | Кнопки в карточке или клавиши 1 / 2 |
| Отменить перемещение до атаки | Кнопка «Отменить шаг» или U |
| Завершить ход | Кнопка или Enter |
| Пауза | Esc |

Голубая подсветка показывает клетки движения. Красная — цели текущей атаки. При наведении панель справа показывает точный урон, стоимость пути, отбрасывание, падение, опасную клетку и контратаку. Если приказ запрещён, там указана причина. Пунктир между вражеским бойцом и союзником показывает доступную атаку врага на текущем поле.

В меню паузы доступны громкость, скорость, режим высокого контраста и отключение анимации движения.

## Правила высоты

Клетки имеют высоту 0–2. Обычный подъём возможен на один уровень, по лестнице — на два. Подъём и обломки повышают стоимость перемещения; сапоги склона убирают доплату за подъём. Спуск более чем на два уровня запрещён. Рельеф и укрытия перекрывают линию обзора. Удар сверху даёт +1 урон; выстрел снизу ослаблен. Толчок на более низкую клетку может нанести урон падением. Вода непроходима; ловушка и костёр наносят урон по своим правилам. Укрытие можно разбить, открыв линию обзора. Хрупкий мост можно обрушить; инженер может подорвать соседний мост, и боец на нём погибнет. Результат виден в предпросмотре.

## Бойцы

| Класс | Роль и приём |
| --- | --- |
| Лучник | Дальний бой по чистой линии обзора; прицельный выстрел |
| Мечник | Ближний бой и удержание прохода; толчок |
| Копейщик | Удар по прямой через союзника; натиск с отбрасыванием |
| Щитоносец | Защита соседей; стража |
| Разведчик | Быстрый обход и фланг; рывок |
| Инженер | Контроль клеток; установка ловушки |

У каждого класса две специализации. Модификаторы и артефакты имеют видимую стоимость и ограничения; их свойства доступны в карточке бойца. ИИ использует те же правила и видимое состояние, что и игрок.

## Сохранения и повтор

Незаконченный матч сохраняется автоматически в Local Storage после каждого приказа. В главном меню доступно «Продолжить». После завершения матча там появляется «Последний повтор» с пошаговой перемоткой. Статистика завершённых матчей хранится локально. Симуляция отделена от отрисовки; `GameState` и журнал команд сериализуются в JSON, а `replayGame` восстанавливает матч из исходной конфигурации и команд.

## Проверка и workbench

`npm test` проверяет путь, высоту, обзор, классы, сборки, артефакты, отмену, победу, replay и решения ИИ. Браузерная smoke-проверка:

```bash
node scripts/browser-smoke.mjs
```

Она запускает установленный локальный Chromium и сохраняет кадры в `workbench/shots/`. Страница `/workbench/` показывает снимки, результаты критиков и журналы headless-матчей.

## Известные ограничения

- Визуальные эффекты, звуки и тихая музыкальная тема синтезируются локально через Canvas/WebAudio; отдельных аудиофайлов нет.
- Камера не вращается: фиксированная изометрия сохраняет ориентацию и одинаковую геометрию клика.
- Оценка баланса продолжается: результаты независимого self-play и следующий проверяемый шаг лежат в `workbench/` и `NEXT_STEPS.md`.
