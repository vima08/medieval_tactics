# Пепел и знамя

Локальная браузерная тактика о борьбе за перевал. Приказы детерминированы: прогноз атаки использует тот же расчёт, что и исполнение.

## Запуск

Требуется Node.js 20+.

```bash
npm install
npm run dev
```

Откройте адрес, напечатанный Vite (обычно http://localhost:5173/).

```bash
npm run build
npm test
```

На Windows PowerShell с запрещённым запуском сценариев используйте `npm.cmd` вместо `npm`.

## Режимы и цель

- **Обучение:** компактная карта, пошаговые подсказки, победа над вражеским командиром ♛.
- **Схватка с ИИ:** большая карта 18×18, три уровня сложности и выбор цели перед боем.
- **Локальный PvP:** два игрока по очереди собирают составы и играют на одном устройстве. Цель выбирает первая сторона до набора второго отряда.

Для основного матча доступны три цели: **контроль огней**, **победить командира ♛** и **победить всех бойцов**. При контроле нужно удерживать хотя бы две из четырёх точек в конце полного раунда: серия растёт на одно очко и сбрасывается при потере контроля. Побеждает сторона, набравшая 5 очков с отрывом. При победе над командиром гибель обычных бойцов сама по себе не завершает матч; при уничтожении отряда гибель одного командира также не завершает матч. Полный разгром стороны завершает любой режим. На 12-м раунде незавершённый бой за контроль решается по очкам, а другие цели — по числу выживших, затем по оставшемуся здоровью; возможна ничья.

До большой схватки выберите 3–5 бойцов в пределах бюджета 25. На отряд доступно не более двух артефактов. Три готовых состава помогают начать быстро; собственный состав сохраняется в браузере.

## Учебная кампания «Дорога шести клятв»

В главном меню выберите **Кампания**. Шесть авторских карт постепенно вводят бойцов; победа открывает следующую главу. Отряды подготовлены заранее, без модификаторов и артефактов, чтобы сначала изучить базовые правила.

| Глава | Новый боец | Карта | Задача |
| --- | --- | --- | --- |
| Зольный брод | Мечник | 8×7 | Победить командира |
| Сторожевая терраса | Лучник | 9×8 | Победить весь отряд |
| Копейные ступени | Копейщик | 10×8 | Победить командира |
| Ворота дозора | Щитоносец | 10×9 | Удержать оба огня два раунда подряд |
| Тропа в тростниках | Разведчик | 11×9 | Победить командира |
| Последняя печь | Инженер | 12×10 | Победить весь отряд |

В бою отображаются короткие шаги освоения нового класса. Они необязательны для победы и отмечают использование соответствующих команд. Боевую цель нужно выполнить за 12 раундов; ожидание окончания срока означает поражение. В главе про удержание уничтожение защитников не заменяет захват огней. Пройденные главы можно повторять. Прогресс и незаконченная миссия сохраняются в браузере; «Продолжить» восстанавливает текущий бой.

### Источники урона

Над пострадавшим бойцом появляются фактически потерянное здоровье и причина: например, **−2 · Ловушка**, «Костёр», «Падение», «Столкновение», «Контратака» или класс нападающего. Если один удар вызывает несколько эффектов, подпись перечисляет их. При движении подпись появляется после прибытия на опасную клетку; причины ловушки и костра также остаются в хронике движения.

Ловушка и костёр срабатывают на конечной клетке перемещения, а не на промежуточных клетках маршрута. Лучник не стреляет по соседней цели, но может стрелять по дальней. Щитоносец постоянно защищает соседей; стража дополнительно защищает его самого. Рывок разведчика расходует действие вместо атаки.

## Управление

| Действие | Управление |
| --- | --- |
| Выбрать бойца / клетку / цель | ЛКМ |
| Ударить по хрупкому мосту | Shift + ЛКМ при выбранном бойце |
| Переключить своего бойца | Tab |
| Отменить выбор | ПКМ |
| Панорама | Перетаскивание ЛКМ по полю или стрелки |
| Масштаб | Колесо мыши |
| Обычная атака / особый приём | Кнопки в карточке или клавиши 1 / 2 |
| Отменить перемещение до атаки | Кнопка «Отменить шаг» или U |
| Завершить ход | Кнопка или Enter |
| Пауза | Esc |

Голубая подсветка показывает клетки движения. Красная — цели текущей атаки. При наведении панель справа показывает точный урон, стоимость пути, отбрасывание, падение, опасную клетку и контратаку. После попадания фактический урон кратко появляется числом над пострадавшим бойцом, в том числе при просмотре повтора. Если приказ запрещён, там указана причина. Пунктир между вражеским бойцом и союзником показывает доступную атаку врага на текущем поле.

В меню паузы доступны громкость, скорость, режим высокого контраста и отключение анимации движения.

## Правила высоты

Клетки имеют высоту 0–2. Обычный подъём возможен на один уровень, по лестнице — на два. Подъём и обломки повышают стоимость перемещения; сапоги склона убирают доплату за подъём. Спуск более чем на два уровня запрещён. Рельеф и укрытия перекрывают линию обзора. Удар сверху даёт +1 урон; выстрел снизу ослаблен. Толчок на более низкую клетку может нанести урон падением. Вода непроходима; ловушка и костёр наносят урон по своим правилам. Укрытие можно разбить, открыв линию обзора. Хрупкий мост можно обрушить; инженер может подорвать соседний мост, и боец на нём погибнет. Результат виден в предпросмотре.

## Бойцы

| Класс | Роль и приём |
| --- | --- |
| Лучник | Дальний бой по чистой линии обзора; прицельный выстрел |
| Мечник | Ближний бой и удержание прохода; толчок |
| Копейщик | Удар по прямой через союзника; натиск с отбрасыванием |
| Щитоносец | Защита соседей; стража |
| Разведчик | Быстрый обход и фланг; рывок |
| Инженер | Контроль клеток; установка ловушки |

У каждого класса две специализации. Модификаторы и артефакты имеют видимую стоимость и ограничения; их свойства доступны в карточке бойца. ИИ использует те же правила и видимое состояние, что и игрок.

## Сохранения и повтор

Незаконченный матч сохраняется автоматически в Local Storage после каждого приказа. В главном меню доступно «Продолжить». После завершения матча там появляется «Последний повтор» с пошаговой перемоткой. Статистика завершённых матчей хранится локально. Симуляция отделена от отрисовки; `GameState` и журнал команд сериализуются в JSON, а `replayGame` восстанавливает матч из исходной конфигурации и команд.

## Проверка и workbench

`npm test` проверяет путь, высоту, обзор, классы, сборки, артефакты, отмену, победу, replay и решения ИИ. Браузерная smoke-проверка:

```bash
node scripts/browser-smoke.mjs
```

Она запускает установленный локальный Chromium и сохраняет кадры в `workbench/shots/`. Страница `/workbench/` показывает снимки, результаты критиков и журналы headless-матчей.

Полный браузерный проход кампании после сборки (Node.js 22.6+ и установленный Chromium Playwright):

```bash
npm run build
node --experimental-strip-types scripts/campaign-browser.mjs
```

Сценарий проходит все шесть миссий через интерфейс, сверяет команды с детерминированными журналами, проверяет открытие глав, восстановление партии и урон ловушки. Он использует собранные локальные файлы, отдельный dev-сервер не требуется.

## Спрайтовые анимации

Все шесть классов используют оригинальный прозрачный атлас, созданный встроенным imagegen: [fighters-v2.png](public/sprites/fighters-v2.png). У каждого класса четыре кадра: стойка, два шага и удар. Фигура разворачивается к цели; попадание кратко подсвечивает её, гибель сопровождается затуханием. Цвет основания обозначает команду. Движение следует рассчитанному маршруту, скорость зависит от настройки; режим без анимации сохраняет неподвижный кадр.

```bash
npm run build
node --experimental-strip-types scripts/sprite-browser.mjs
```

Проверка снимает стойку, ходьбу и удар каждого класса, проверяет alpha атласа и совпадение результата команды с правилами. Кадры находятся в `workbench/sprite-frames/`, промпты — в `workbench/sprite-prompts.md`. При недоступности ассета игра использует прежнюю отрисовку фигур.

## Известные ограничения

- Визуальные эффекты, звуки и тихая музыкальная тема синтезируются локально через Canvas/WebAudio; отдельных аудиофайлов нет.
- Камера не вращается: фиксированная изометрия сохраняет ориентацию и одинаковую геометрию клика.
- Оценка баланса продолжается: результаты независимого self-play и следующий проверяемый шаг лежат в `workbench/` и `NEXT_STEPS.md`.
