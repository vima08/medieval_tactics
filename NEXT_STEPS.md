# Следующая итерация

Срез на 2026-10-01. Проект оставлен запускаемым. В репозитории пока нет `HEAD`: все файлы текущего рабочего дерева не закоммичены, поэтому проверенная точка — именно это рабочее дерево, а не commit.

## Что работает

- Локальная браузерная игра «Пепел и знамя»: обучение 8×8, основной бой 18×18 против ИИ и hot-seat PvP с отдельным выбором отрядов.
- Детерминированные правила движения, высоты, обзора, боя, отбрасывания и падения; шесть классов с вариантами, модификаторами и артефактами; бюджет набора и готовые составы.
- Предпросмотр действий, угроз и затрат пути; отмена перемещения до атаки; разрушаемые мосты и укрытия; три уровня ИИ.
- Сохранение партии и состава в браузере, локальная статистика, просмотр журнала команд, настройки звука и доступности, анимированные перемещения и процедурный звук.
- Четыре контрольные точки основного поля, оценка после полного раунда, цель — 5 очков с отрывом, предел 12 раундов. Если команда удерживает меньше двух точек, её серия очков сбрасывается; это правило теперь явно показано в интерфейсе.

## Запуск и проверки

```bash
npm install
npm run dev
npm run build
npm test
```

Откройте адрес Vite, обычно `http://localhost:5173/`. На Windows PowerShell при блокировке `npm.ps1` используйте `npm.cmd` вместо `npm`. Для автоматизации браузера при работающем dev-сервере:

```bash
node scripts/browser-smoke.mjs
node --experimental-strip-types scripts/terrain-browser.mjs
node scripts/pvp-browser.mjs
node --experimental-strip-types scripts/animation-browser.mjs
```

Последний полный прогон: `npm.cmd run build` успешен; `npm.cmd test` — 5 файлов, **33/33 теста прошли**. Повторный `node scripts/browser-smoke.mjs` прошёл с семью кадрами и без ошибок страницы. Сценарий обрушения моста, передача хода в PvP и анимация перемещения также проходили без ошибок. Для браузерных скриптов нужен доступный Chromium Playwright; обычная игра не требует автоматизации.

## Крупнейший оставшийся недостаток

Баланс составов не готов: в независимой серии первый пресет победил второй во всех **8 из 8** проверенных парных сценариев с переменой стороны и сложности. Разведчики не выжили ни в одном из 28 развёртываний серии. Эксперимент с заменами второго пресета дал улучшения лишь в части сценариев и не выявил устойчивого исправления; неподтверждённую замену не внесли. В матчах игрока также обнаружено, что сброс серии контроля с 4/5 до 0/5 ощущается резким. Интерфейс теперь сообщает правило, но его игровой эффект ещё не перепроверен после возможной смены правила. Вертикальный срез нельзя считать сбалансированным коммерческим релизом.

## Точная следующая итерация Gauntlet Loop

1. На копии текущего состояния сравнить накопительные очки контроля и действующую серию на тех же полных headless-матчах. Сохранить журналы, длительность и частоту камбэков; выбрать правило по последствиям в игре, а не по одному числу побед.
2. Изолировать причину превосходства первого пресета: повторить 8 парных сценариев с зеркальной сменой сторон, точечно менять состав второго пресета или оценку ИИ, фиксировать выбор и выживаемость разведчика. Внести только изменение, которое улучшает обе стороны без доминирующего нового билда.
3. Повторить те же сценарии и один полный браузерный матч, проверить точность предпросмотра и завершение PvP; затем снова запустить сборку, тесты и независимую проверку тактики и UX. Сохранить новые кадры и отчёты в `workbench/`.

Дополнительная визуальная полировка нужна после баланса: свежий visual critic ещё не оценивал последние пронумерованные маркеры соседних целей. Полные 15–30 минут реального матча и коммерческий уровень качества не доказаны.
