### Следующая необязательная итерация Gauntlet Loop

1. Дать новичку на физическом планшете пройти весь путь без подсказок разработчика; записать время, ошибки понимания, жесты и комфорт чтения/звучания.
2. Сохранить replay и заметки, выбрать одну крупнейшую воспроизведённую проблему.
3. Исправить её и повторить полный путь с другим новичком, затем production build и тесты.
4. Общий баланс свободных составов и исторические дефекты проверять отдельно по `defects.md`; завершение сюжетного плана не доказывает идеальный баланс всей игры.

Исторические вопросы: парная серия пресетов после исправления натиска/стражи, удержание точек ИИ, проверка геометрии факультативных уроков, более подробные анимации попадания/гибели. Pages workflow уже поддерживает master/main; удалённый deploy требует push и проверки Settings → Pages → Source: GitHub Actions.
