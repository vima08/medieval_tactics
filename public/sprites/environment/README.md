# Окружение · оригинальные спрайты

Все восемь PNG созданы встроенным imagegen для «Пепла и знамени», с настоящим alpha-каналом. Это отдельные ассеты, не лист с нарезкой. Полные промпты: `workbench/environment-prompts.md`.

| Ассет | Правило/отображение |
| --- | --- |
| `brazier-v1.png` | Жаровня на клетке костра: 1 урон при завершении движения |
| `torch-v1.png` | Факел, вариант той же клетки огня с тем же уроном |
| `rock-v1.png` | Разрушаемое укрытие; видимая полоса прочности |
| `trap-v1.png` | Вооружённая ловушка; маркер −2, исчезает после срабатывания |
| `bridge-v1.png` | Деревянный настил одной клетки; хрупкий мост имеет дополнительные трещины |
| `banner-v1.png` | Сигнальная цель в режиме контроля; при занятии частично прозрачна |
| `rubble-v1.png` | Обломки на труднопроходимой клетке, в том числе после разрушения укрытия |
| `stairs-v1.png` | Ступени на существующих лестничных клетках |

Размещение и масштаб: `src/environment-sprites.ts`. Границы изображения определяются по alpha. Подсветки движения рисуются под предметами; опасность обозначена отдельным янтарным контуром и числом урона. Факел/жаровня выбираются по координатам клетки, симуляция для обоих одинакова. Искры и свет огня рисуются локально и отключаются при уменьшении движения. При недоступности PNG остаётся прежняя отрисовка объекта.

Проверка: `npm run build`, затем `node --experimental-strip-types scripts/environment-browser.mjs`. Реальные кадры — `workbench/environment-shots/`, результаты — `workbench/environment-browser-results.json`.
