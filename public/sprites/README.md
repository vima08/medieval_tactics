# Спрайты бойцов

`fighters-v2.png` — используемый в игре атлас 1024×1536 с настоящим alpha-каналом. Создан встроенным imagegen; внешние API во время игры не нужны. `fighters-v1.png` — исходный вариант генерации, в отрисовке не используется.

Композиция: 4 столбца × 6 строк. Строки: мечник, лучник, копейщик, щитоносец, разведчик, инженер. Столбцы: стойка, левый шаг, правый шаг, удар. Генерация не соблюдает границы ячеек строго: отрисовка находит 24 целых силуэта по связным областям alpha, затем определяет индивидуальные прямоугольники и положение ступней. Масштаб общий. Противоположное направление — зеркальное отражение; команда определяется цветом основания. Анимации попадания и гибели используют подсветку/затухание готового спрайта.

Загрузка и воспроизведение: `src/fighter-sprites.ts`. При недоступности PNG используется прежняя геометрическая фигура. Настройка «Без анимации движения» отключает смену кадров и смещение; фактические правила боя от анимации не зависят.

Промпты генерации и извлечения фона: `workbench/sprite-prompts.md`. Реальные кадры: `workbench/sprite-frames/`.
